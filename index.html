EasiShare 快速上手指南（英文界面版）

适用对象：公司内部各部门用户、外部合作伙伴对接人
系统版本：EasiShare Web Portal（英文菜单）
目标：用 EasiShare 安全分享超大文件、跨部门协作、向外部伙伴收/发文件

1. EasiShare 是什么？

EasiShare 是一个企业级安全文件共享与协作平台，用来替代邮件附件、U 盘、微信/QQ 传文件、FTP、消费级网盘。

  • 超大文件传输：不依赖邮件附件大小限制
  • 内外协作：部门之间、公司与供应商/客户/审计方之间都能用
  • 安全可控：Link Expiry、OTP、View Only、下载次数、水印、审计日志
  • 集中治理：RBAC、Retention、Recycle Bin、Versioning、Check In/Out
  • 多端访问：Web、Desktop Sync、Mobile App
  • 部署灵活：On-Prem / Private Cloud / Hybrid / Air-Gap
一句话：EasiShare = 企业版“安全网盘 + 大文件快递 + 项目协作空间 + 外部收件箱”。

2. 登录与界面

  1. 打开公司 EasiShare 地址：https://clientname.easishare.com/web
  2. 输入 Username / Password，或使用 SSO / AD / Entra ID 登录
  3. 左侧常见节点：
    • My Drive：个人文件
    • Shared Drives：被授权协作的文件夹
    • Shared In：别人分享给你
    • Shared Out：你分享给别人
    • File Request：让外部上传文件
    • Recycle Bin：回收站
    • Monitor：关注文件变化

3. 上传大文件

  • 按钮上传：进入文件夹 → 点 Upload
  • 拖拽上传：把文件拖进浏览器窗口
  • 桌面同步：安装 EasiShare Desktop → 用 Selective Sync 控制同步范围
超大文件不要再用邮件，直接传 EasiShare。

4. 发大文件给部门/外部伙伴：Share

  1. 勾选文件/文件夹 → 点 Share
  2. 填写 Name、Email，如启用 OTP 再填 Mobile Number
  3. 设置：
    • Link Expires：过期时间
    • OTP：手机验证码
    • Share with View Only：只能看不能下载
    • No. of Attempts：下载次数限制
    • Notifications：被查看/下载时通知你
  4. 点 Share 发送链接
场景推荐设置
内部普通文件默认 Share
给客户看方案View Only + Link Expires
发机密图纸给供应商OTP + Link Expires + No. of Attempts = 3
合同/法务文件View Only + 水印 + OTP

5. 和团队/伙伴一起改文件：Manage

  1. 进入或新建文件夹 → 点 Manage
  2. 添加用户/组，分配权限：
    • Reader：只读
    • Contributor：可上传/编辑
    • Author：可删除
    • Owner：完全控制（通常仅内部）
  3. 可设置 Folder Expiry、禁用 Download、开启 Web Edit
Share = 发文件（静态副本）；Manage = 开项目空间（双向协作）。

6. 让外部伙伴发文件给你：File Request

  1. 进入目标文件夹 → 点 File Request
  2. 填写请求人 Name / Email / Mobile Number
  3. 设置：
    • Link Expiry
    • OTP
    • Restrict File Types（如 pdf, zip, dwg）
    • No. of Upload Attempts
    • Notifications
  4. 点 Send Request

对方不需要 EasiShare 账号，上传前可做 AV / 文件类型检查。

7. 收回 / 查看分享

  • Shared Out → Edit Share 改过期/下载权限
  • Shared Out → Unshare 立即作废链接
  • Shared In 查看别人发来的文件

8. 独占编辑：Check Out / Check In

  1. 选中文件 → Check Out（别人只能看）
  2. 编辑完 → Check In（生成新版本）
  3. 改错了 → Discard Check Out

9. 版本管理：Versioning

  • View File Version
  • Create New Version
  • Restore Version

10. 盯文件变化：Monitor

  • 选中文件/文件夹 → Monitor
  • 有上传/下载/删除/编辑时收到提醒
  • 不需要时 → Stop Monitoring

11. 外发审批：Workflow

  1. Owner 创建 Workflow
  2. 指定审批人
  3. 用户外发/上传敏感文件 → 进入 Pending Approvals
  4. 审批人 Approve / Reject with Comments

12. 手机端

  • 安装 EasiShare App（iOS / Android）
  • 可 Share、File Request、预览、上传照片/扫描件
  • 设备丢失 → 通知 IT 执行 Remote Wipe

14. 安全底线

  • 涉敏文件：必须 OTP 或 SSO
  • 合同/财务/客户数据：View Only + Link Expires
  • 项目结束：Unshare + Folder Expiry
  • 离职/转岗：通知 IT 回收 Owner 权限
  • 丢手机：立即 Remote Wipe
